1. Define SEO and explain its purpose in web development.
Search Engine Optimisation (SEO) is the process of improving a website so search engines can understand its content and display it in relevant search results. Its purpose is to help the intended audience discover the website more easily.

2. Explain how SEO practices can improve user experience (UX) and website performance.
SEO encourages clear headings, useful page descriptions, mobile-friendly layouts and organised content. These features make information easier to find and understand. Optimised images and clean code can also improve loading speed.

3. Discuss the benefits of implementing SEO on a website.
SEO can improve website visibility, attract people searching for relevant services and help build trust. It can bring visitors to the site over time and make it easier for potential customers to find contact information.

4. Explain and demonstrate specific SEO techniques using HTML, CSS and JavaScript where applicable.
Each HTML page includes a unique title, meta description and relevant keywords. Semantic headings, descriptive links and form labels organise information. Responsive CSS supports mobile users. JavaScript adds a mobile menu, service search and sorting to improve usability; JavaScript alone does not guarantee higher search rankings.
